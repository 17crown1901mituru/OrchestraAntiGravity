Modifier ou désactiver les raccourcis clavier
---------------------------------------------

Pour modifier ou désactiver les raccourcis clavier dans la Google Cloud console, procédez comme suit :

1.  Accédez à [Google Cloud console](https://console.cloud.google.com/?hl=fr).
    
2.  Ouvrez la boîte de dialogue des raccourcis clavier en appuyant sur ? ou Ctrl+Maj+/ (Commande+Maj+/ sous macOS) Vous pouvez également cliquer sur **Assistance**, puis sur **Configurer les raccourcis clavier**.
    
3.  Pour désactiver un raccourci, décochez la case correspondante. Pour le modifier, cliquez sur **Modifier le raccourci**, puis saisissez un nouveau raccourci.
    
4.  Lorsque vous avez terminé, cliquez sur **Enregistrer**.
    

Lorsque vous modifiez des raccourcis clavier, tenez compte des points suivants :

*   Votre raccourci de remplacement doit être une combinaison de Ctrl ou Maj avec une clé imprimable.
    
*   Un même raccourci ne peut pas être attribué à plusieurs actions.
    
*   Pour revenir aux raccourcis clavier d'origine, cliquez sur **Restaurer toutes les valeurs par défaut** dans la boîte de dialogue des raccourcis clavier.
    

Afficher les raccourcis clavier contextuels
-------------------------------------------

Vous pouvez ouvrir une superposition qui affiche les raccourcis clavier contextuels en fonction de ce qui est affiché à l'écran ou de l'élément d'interface utilisateur ciblé, tel que les éditeurs de code, les tables et les barres de menu.

Pour afficher la superposition dans la Google Cloud console, procédez comme suit :

1.  Accédez à [Google Cloud console](https://console.cloud.google.com/?hl=fr).
    
2.  Ouvrez la boîte de dialogue des raccourcis clavier en appuyant sur ? ou Ctrl+Maj+/ (Commande+Maj+/ sous macOS) Vous pouvez également cliquer sur **Assistance**, puis sur **Configurer les raccourcis clavier**.
    
3.  Sélectionnez **Afficher l'assistant de raccourci**, puis cliquez sur **Enregistrer**.
