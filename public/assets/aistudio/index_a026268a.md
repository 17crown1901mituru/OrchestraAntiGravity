# Documentation de Cloud&nbsp;Quotas &nbsp;|&nbsp; Google Cloud Documentation
URL: https://docs.cloud.google.com/docs/quotas

Cloud Quotas permet aux clients de gérer les quotas pour tous leurs services Google Cloud . Avec Cloud Quotas, les utilisateurs peuvent facilement surveiller l'utilisation des quotas, créer et modifier des alertes de quota, et demander des ajustements de limites de quotas. Les quotas sont gérés via le tableau de bord Cloud Quotas ou l'API Cloud Quotas. [En savoir plus](https://docs.cloud.google.com/docs/quotas/overview?hl=fr)
