# Controles de gerenciamento de dados &nbsp;|&nbsp; Security &nbsp;|&nbsp; Google Cloud Documentation
URL: https://docs.cloud.google.com/docs/security/security-best-practices-catalog/data-management

Este documento inclui as práticas recomendadas e as diretrizes para sistemas de gerenciamento de dados ao executar cargas de trabalho no Google Cloud.

Sistemas de gerenciamento de dados, como o [BigQuery](https://docs.cloud.google.com/bigquery/docs/introduction?hl=pt-br) e o [Cloud Storage](https://docs.cloud.google.com/storage/docs/introduction?hl=pt-br), permitem armazenar os dados necessários para seus fluxos de trabalho, incluindo dados de treinamento, artefatos de modelo e dados de produção.

----------------

Esses controles se aplicam a todos os sistemas de gerenciamento de dados.
