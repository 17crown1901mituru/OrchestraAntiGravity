# Data protection guidelines &nbsp;|&nbsp; Security &nbsp;|&nbsp; Google Cloud Documentation
URL: https://docs.cloud.google.com/docs/security/gcmvsp/data-protection

The following guidelines for the minimum viable security platform align with the data protection pillar.

Basic level guidelines
----------------------

Implement the following data protection guidelines first.

<table><tbody><tr><th>Item</th><td><h3 id="use-uniform-bucket-level-access" data-text="Use uniform bucket-level access" tabindex="-1">Use uniform bucket-level access</h3></td></tr><tr><th>Description</th><td><div><p>The <code translate="no" dir="ltr">storage.uniformBucketLevelAccess</code> boolean constraint requires buckets to use uniform bucket-level access. Uniform bucket-level access lets you only use bucket-level Identity and Access Management (IAM) permissions to grant access to your Cloud Storage resources.</p><p>Using two different and conflicting systems to manage permissions on storage buckets is complex and a common cause of accidental data leaks. This setting turns off the legacy system (access control lists, or ACLs) and makes the modern, centralized system (IAM) the single source of truth for all permissions.</p></div></td></tr><tr><th>Related information</th><td><ul><li><a href="https://docs.cloud.google.com/storage/docs/org-policy-constraints#uniform-access">Require uniform bucket-level access</a></li></ul></td></tr><tr><th>Item ID</th><td>MVSP-CO-1.42</td></tr><tr><th>Mapping</th><td><p>Related NIST-800-53 controls:</p><ul><li>AC-3</li><li>AC-17</li><li>AC-20</li></ul><p>Related CRI profile controls:</p><ul><li>PR.AC-3.1</li><li>PR.AC-3.2</li><li>PR.AC-4.1</li><li>PR.AC-4.2</li><li>PR.AC-4.3</li><li>PR.AC-6.1</li><li>PR.PT-3.1</li><li>PR.PT-4.1</li></ul><p>Compliance Manager control:</p><ul><li><a href="https://docs.cloud.google.com/security-command-center/docs/compliance-manager-cloud-controls#enforce-uniform-bucket-level-access">Enable Uniform Bucket-Level Access on Cloud Storage Buckets</a></li></ul></td></tr></tbody></table>

<table><tbody><tr><th>Item</th><td><h3 id="restrict-cloud-sql-public-ip-addresses" data-text="Restrict Cloud SQL public IP addresses" tabindex="-1">Restrict Cloud SQL public IP addresses</h3></td></tr><tr><th>Description</th><td><div><p>Prevent Cloud SQL from having a public IP address and being directly exposed to the internet by setting the <code translate="no" dir="ltr">constraints/sql.restrictPublicIp</code> organization policy constraint. After you implemented the basic guidelines, implement the following data protection guidelines.

<table><tbody><tr><th>Item</th><td><h3 id="block-public-access-to-cloud-storage-buckets" data-text="Block public access to Cloud Storage buckets" tabindex="-1">Block public access to Cloud Storage buckets</h3></td></tr><tr><th>Description</th><td><p>The <code translate="no" dir="ltr">storage.publicAccessPrevention</code> boolean constraint prevents storage buckets from being accessed from public sources without authentication. It disables and blocks access control lists (ACLs) and Identity and Access Management (IAM) permissions that grant access to <code translate="no" dir="ltr">allUsers</code> and <code translate="no" dir="ltr">allAuthenticatedUsers</code>. This constraint acts as an organization-wide safety net that actively blocks any setting that would make a bucket publicly accessible.</p></td></tr><tr><th>Related information</th><td><ul><li><a href="https://docs.cloud.google.com/storage/docs/public-access-prevention">Public access prevention</a></li></ul></td></tr><tr><th>Item ID</th><td>MVSP-CO-1-43</td></tr><tr><th>Mapping</th><td><p>Related NIST-800-53 controls:</p><ul><li>AC-3</li><li>AC-17</li><li>AC-20</li></ul><p>Related CRI profile controls:</p><ul><li>PR.AC-3.1</li><li>PR.AC-3.2</li><li>PR.AC-4.1</li><li>PR.AC-4.2</li><li>PR.AC-4.3</li><li>PR.AC-6.1</li><li>PR.PT-3.1</li><li>PR.PT-4.1</li></ul><p>Compliance Manager control:</p><ul><li><a href="https://docs.cloud.google.com/security-command-center/docs/compliance-manager-cloud-controls#enforce-public-access-prevention">Enforce Public Access Prevention</a></li></ul></td></tr></tbody></table>

<table><tbody><tr><th>Item</th><td><h3 id="ensure-bigquery-datasets-arent-publicly-readable-or-set-to-allauthenticatedusers" data-text="Ensure BigQuery datasets aren't publicly readable or set to allAuthenticatedUsers" tabindex="-1">Ensure BigQuery datasets aren't publicly readable or set to allAuthenticatedUsers</h3></td></tr><tr><th>Description</th><td><div><p>Ensure that BigQuery doesn't have datasets that are open to public access unless the datasets are intended to be public.
